# Aleph Contracting Co.

- **Industry:** Contracting
- **Site type:** Local trade services
- **Framework:** Static HTML/CSS/JavaScript
- **Output:** `dist/`
- **Run:** Open `dist/index.html` or serve the folder with any static server.

A conversion-focused contracting demo for estimates, service categories, and project confidence.

## Features

- Responsive single-page presentation
- Keyboard-accessible navigation and form controls
- Reduced-motion support
- Simulated form with no transmission or storage
- Visible UVP demo disclosure
